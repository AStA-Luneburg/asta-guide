# Seiten bearbeiten

Dies ist die wichtigste Funktion für alle: Jedes Referat, jeder Servicebetrieb und das
StuPa besitzt eigene Seiten, die ihr selbst pflegt.

## In den Editor kommen

**Weg 1 — aus der Seite heraus.** Ihr seid auf der Seite eingeloggt? Dann hat die
Admin-Leiste oben den Eintrag **Bearbeiten**. Ein Klick öffnet genau diese Seite im
Editor.

**Weg 2 — aus dem Admin-Bereich.** Links in der Seitenleiste auf **Seiten** klicken, in
der Liste die Seite suchen und auf **Bearbeiten** klicken.

Beide Wege führen in denselben Block-Editor.

![Seitenliste im Adminbereich mit dem Link Bearbeiten](/img/guide-gwyneth/seiten-liste.png)

*Weg 2: In der Seitenliste steht hinter jeder Seite der Link **Bearbeiten**.*

## Der Block-Editor

Der Editor ist ein Arbeitsbereich aus **Blöcken**. Ein Absatz ist ein Block, eine
Überschrift ist ein Block, ein Bild ist ein Block, eine Kachelreihe ist eine Gruppe von
Blöcken.

| Was ihr wollt | Wie |
|---|---|
| Text schreiben | In den Arbeitsbereich klicken und lostippen |
| Neuen Block einfügen | **+** zwischen zwei Blöcken, oder oben links der Block-Inserter |
| Block-Typ schnell finden | `/` tippen und den Namen eingeben, z. B. `/bild` |
| Block verschieben | Pfeile in der Block-Werkzeugleiste oder am Griff (sechs Punkte) ziehen |
| Block löschen | Block auswählen, dann `Entf` bzw. im Menü der Werkzeugleiste |
| Block-Einstellungen | Block auswählen, rechts in der Seitenleiste erscheinen seine Optionen |
| Letzte Änderung zurücknehmen | `Cmd/Ctrl + Z` |

Für wiederkehrende Layouts müsst ihr keine Blöcke zusammensetzen: Es gibt fertige
**Bausteine**. Siehe [Bausteine](./bausteine.mdx).

## Seite veröffentlichen

Oben rechts auf **Aktualisieren** klicken. Der Button **Vorschau** zeigt die Seite, bevor
sie für alle sichtbar ist.

:::caution Vor dem Aktualisieren
Klickt einmal auf **Vorschau** und prüft, ob die Änderung das gewollte Ergebnis hat.
Sobald ihr aktualisiert, sieht die Änderung jede und jeder Besuchende der Website.
:::

:::warning Nicht auf Entwurf umstellen
Der Menüpunkt **Auf Entwurf umstellen** nimmt die Seite aus der Öffentlichkeit. Wer die
URL aufruft, bekommt dann keine Inhalte mehr. Wenn eine Seite vorübergehend weg soll,
sprecht das mit der Webmaster-Stelle ab.
:::

## Ältere Fassungen wiederherstellen

WordPress speichert bei jedem Aktualisieren eine Revision. Rechts in der Seitenleiste im
Reiter „Seite“ findet ihr unter **Revisionen** die Liste der Fassungen; ein Klick zeigt
den Unterschied, eine Schaltfläche stellt die Fassung wieder her.

## Zwei Dinge, die überraschen

- **Der Titel ist die H1 der Seite.** Schreibt ihn nicht zusätzlich in den Inhalt.
- **Ein neuer Titel ändert die URL nicht.** Die URL bleibt beim Anlegen stehen. Ist eine
  neue URL gewünscht, ist das ein Fall für die Webmaster-Stelle (Weiterleitung).
