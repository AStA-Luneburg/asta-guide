# Checkliste vor dem Veröffentlichen

Diese Liste gilt für Beiträge und Seiten. Sie ist kurz genug, um sie wirklich zu benutzen.

## Inhalt

- [ ] **Titel** ist konkret und ohne Clickbait
- [ ] **Textauszug** ausgefüllt, 120–155 Zeichen, klingt wie ein Satz
- [ ] **Eine** Kategorie gewählt, „Unkategorisiert“ nicht angehakt
- [ ] **Beitragsbild** gesetzt
- [ ] Keine Platzhalter: „Text steht aus“, „Lorem ipsum“, Beispieltexte aus Bausteinen
- [ ] Keine zwei Wahrheiten: Informationen, die es schon gibt, sind **verlinkt** statt kopiert

## Struktur

- [ ] Der Seitentitel steht **nicht** zusätzlich im Inhalt
- [ ] Überschriften beginnen bei **H2**, Unterabschnitte sind **H3**
- [ ] Keine eigenen Schriftgrößen und keine Hex-Farben
- [ ] Abschnitte sind gegliedert: H2 für Hauptabschnitte, H3 darunter

## Bilder

- [ ] Jedes inhaltstragende Bild hat einen **Alternativtext** (der Editor warnt, wenn keiner gesetzt ist)
- [ ] Dekorative Bilder haben einen **leeren** Alternativtext
- [ ] Dateinamen sind beschreibend (`referat-archipel-logo.jpg`)
- [ ] Fotos sind vor dem Upload verkleinert

## Links

- [ ] Alle Links funktionieren
- [ ] Linktexte sagen, wohin sie führen („Semesterticket beantragen“, nicht „hier klicken“)
- [ ] Externe Links öffnen in einem neuen Tab, wenn das gewollt ist

## Sprachen und Menü

- [ ] Englische Fassung angelegt — oder bewusst zurückgestellt und notiert
- [ ] Bei einer neuen Seite: Eintrag in **beiden** Hauptmenüs
- [ ] Sprachumschalter auf der Seite sichtbar (Verknüpfung vorhanden)

## Vor dem Klick auf „Veröffentlichen“

- [ ] **Vorschau** angesehen, auf Desktop und auf dem Telefon
- [ ] Keine abgeschnittenen Wörter, keine Überlappungen
- [ ] Im **Dunkelmodus** angesehen
- [ ] Bei Veranstaltungen: Datum und Uhrzeit stimmen
